# 📊 Estado Actual del Proyecto (Okupo + Finite)
Fecha: Viernes, 15 de Mayo de 2026

## 🛠️ Lo que ES (Realidad Técnica)
El proyecto es un sistema de gestión de servicios técnicos compuesto por:
1.  **Motor Finite (Rust)**: Backend robusto con arquitectura hexagonal, persistencia en MySQL (prod) y SQLite (test/dev), y lógica financiera avanzada.
2.  **Okupo (Flask)**: Interfaz de usuario que consume la API de Finite para ofrecer servicios de cerrajería, plomería, etc., al cliente final.

### Estado del Motor (Finite):
- ✅ **Estable**: Compilación limpia y pruebas unitarias de dominio aprobadas.
- ✅ **Reset & Seed**: Capacidad de reiniciar el entorno con un comando (`--reset-db`) creando un administrador por defecto.
- ✅ **Sincronizado**: Modelos de datos actualizados (Portafolio, Evidencia, Solicitudes).

### Estado de la Interfaz (Okupo):
- ✅ **Lógica Financiera Migrada**: Los cálculos de desglose de pago e impuestos ya no se hacen en Python; se consultan dinámicamente al motor Rust via `/pagos/desglose`.
- ✅ **Evidencia Multimedia Real**: Implementada la subida de fotos real en el flujo de pedidos. Las imágenes se guardan en el servidor Rust y se vinculan a la solicitud.
- ✅ **Conectividad**: Los endpoints principales (Login, Categorías, Marketplace) son dinámicos y usan un proxy seguro (`/api_proxy`).
